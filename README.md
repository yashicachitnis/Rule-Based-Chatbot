# Rule-Based Chatbot – CodeBot

## Project Description
CodeBot is a simple rule-based chatbot developed using Python. It interacts with users by accepting text input and providing predefined responses based on keywords and conditions.

## Features
- Responds to greetings such as Hello, Hi and Hey.
- Answers basic questions about Python, AI and Programming.
- Provides information about its name and capabilities.
- Displays the current date and time.
- Gives random greeting responses.
- Displays available commands using the menu option.
- Handles unknown questions with a fallback response.
- Allows users to exit the chatbot using Bye or Exit.

## How to Run the Project

1. Install Python 3.12 or later.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   `py chatbot.py`

## How It Works
The chatbot accepts messages from the user and converts them into lowercase. It checks the input against predefined keywords using if-elif-else conditions and returns an appropriate response.

If no keyword matches, the chatbot displays a default response.

## Example

**User:** Hello

**CodeBot:** Hello! Nice to meet you. How can I help you?

**User:** What is Python?

**CodeBot:** Python is a popular programming language known for its simple syntax.

**User:** Bye

**CodeBot:** Goodbye! Have a great day!
